☁️ Đồng bộ dữ liệu — Firebase

Tất cả GV dùng chung 1 Firebase project → dữ liệu tự đồng bộ real-time.
Setup 1 lần, dùng mãi mãi.

📋 Hướng dẫn lấy Firebase config (5 phút)
1. Vào console.firebase.google.com → Đăng nhập Gmail
2. Nhấn "Add project" → đặt tên (VD: speak-shine-lop1) → Continue
3. Vào Firestore Database → Create database → Start in test mode → Next → Enable
3b. Vào Storage → Get started → Start in test mode → Done
4. Vào ⚙️ Project Settings → tab "Your apps" → nhấn icon </> (Web)
5. Đặt tên app bất kỳ → Register → Copy toàn bộ firebaseConfig = { ... }
6. Paste vào ô bên dưới → Kết nối
✅
Chưa sync
💡 Đẩy lên: lưu dữ liệu máy bạn lên cloud → GV khác tải về.
💡 Tải về: lấy dữ liệu mới nhất từ cloud về máy bạn.
